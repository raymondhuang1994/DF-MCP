DF-MCP 0.7.0 adds resumable directory batches, persistent local Wiki drafts, verification against original source versions and locators, and dependency-based rebuild queues.

Install `DF-MCP-0.7.0.zip` or its byte-identical `.skill` file. Each has exactly one root-level `SKILL.md`, Python helpers and pinned parser dependencies. A company-approved Python 3.9+ interpreter and local execution access are required. The package contains no credentials, source documents, Wiki content or index.

Existing source configuration and read-only access safeguards remain. Index and Wiki state stay in a separately configured local folder. Wiki drafts are navigation aids; citation validation does not certify the interpretation. The host agent checks original evidence for factual answers and recompiles affected pages from fresh sources.

Automated validation uses synthetic fixtures across Windows, macOS and Linux. Production network-drive latency, company Microsoft sign-in and real-document acceptance still depend on the target environment. Directory checkpoints improve interruption recovery; they do not promise a fixed scan duration or a complete inventory while scopes remain pending.
